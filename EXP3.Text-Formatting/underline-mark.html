Underline, Mark and Small Tags

These HTML tags are used to change the appearance of text and highlight important content.

Underline Tag

This text is underlined.
The underline tag is used to draw attention to specific text.

Mark Tag

This text is highlighted.
The mark tag is used to highlight text, usually for reference or importance.

Small Tag
